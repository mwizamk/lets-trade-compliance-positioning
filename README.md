# Let's Trade ZM — Subscription Assistance & Compliance Guide

Static GitHub Pages website containing the recommended business positioning discussed for an independent digital subscription assistance service.

## Purpose

The guide explains how to position Let's Trade ZM as an independent service that can help customers understand, choose, purchase and set up legitimate subscriptions without falsely presenting itself as Netflix, Spotify, Amazon, Showmax, Apple, Google or another provider.

## Files

- `index.html` — complete guide
- `style.css` — responsive styling
- `script.js` — local browser checklist persistence

## GitHub Pages

1. Create a new GitHub repository.
2. Upload the three files to the repository root.
3. Commit the files.
4. Open **Settings → Pages**.
5. Enable GitHub Pages using the repository's main branch/root or GitHub Actions.
6. Open the generated Pages URL.

## Important

This is a business-positioning guide, not legal advice.

Platform policies and provider terms can change. Before launching a specific resale, affiliate, payment-handling, account-sharing or support arrangement, verify the relevant provider's current terms, the social platform's current policies, and applicable Zambian commercial/consumer requirements.

Never claim to be an official provider, reseller, partner or support channel unless you actually have that authorization.

## Recommended positioning

> Let's Trade ZM is an independent digital subscription assistance service. We help customers understand available subscription options and, where permitted, assist with subscription purchasing and setup.
